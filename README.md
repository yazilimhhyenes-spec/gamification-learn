# gamification-learn — OOP'yi oynayarak öğren

Nesne Yönelimli Programlamayı (Class, Object, Encapsulation, Inheritance, Polymorphism, Abstraction, Interface, Composition, SOLID) oyunlaştırılmış biçimde öğreten üç sürüm:

| Klasör | Sürüm |
|---|---|
| [`oop-quest-web/`](oop-quest-web) | **Ana sürüm:** tarayıcıda 2D oyun (TypeScript + Vite, gerçek TS derleyicisi tarayıcıda) |
| [`oop-quest-ts/`](oop-quest-ts) | Konsol (terminal) sürümü, TypeScript |
| [`oop-quest.js`](oop-quest.js) | İlk, tek dosyalık JavaScript konsol sürümü |

Web sürümünü çalıştırmak için:

```bash
cd oop-quest-web
npm install
npm run dev
```
